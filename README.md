# Kamikaze IA

Reconstruction de travail du studio IA multimédia. Le code source complet est conservé dans `Kamikaze_IA_Reconstruction.zip` (dossier `Kamikaze_IA/`).

Cette version est une base d'intégration à configurer et tester; elle ne constitue pas encore une application commerciale finalisée. Les clés API doivent être ajoutées uniquement dans les variables d'environnement Render, jamais dans GitHub.
